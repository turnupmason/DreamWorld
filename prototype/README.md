# 镜像小镇 · 交互原型

网页原型，用来演示核心玩法和做用户访谈，不是正式的 iOS App。所有画面都是代码实时画出来的（等距 2.5D），没有用图片素材。

> 现在冻结：正式版改做原生 App + 3D 美术，这里只修 bug 和做访谈。项目文档都在仓库根目录的 `docs/`，代码结构和调试方法见 `docs/原型代码说明.md`。

## 打开方式

- 最简单：直接双击 `index.html`。
- 或者在 `D:\DreamWorld` 里运行 `python -m http.server 5173 --directory prototype`，然后打开 http://localhost:5173 。同一 Wi-Fi 下的手机可以用 `http://<电脑 IP>:5173` 打开，手机上会全屏显示，右上角 🛠 打开原型控制台。

进度存在浏览器本地（localStorage），控制台里的「重置原型」可以从头开始。控制台的「演示：+🪙1000」只是为了方便试商店，正式版没有。

## 五个页签

| 页签 | 内容 |
| --- | --- |
| 🏡 家 | 你自己的家：房子、菜地、牧场、车道、院子。点房子进屋，屋里可以摆家具。「设计」可以挪家具和院子装饰、旋转、换颜色、换墙纸地板、换外墙屋顶颜色。点车换车身颜色。 |
| 🏘️ 小镇 | 整条梧桐街：每家的房子、车、田、牲畜都看得到，头顶显示家产排名。点任意一家进去拜访，可以点赞、留言、送礼、进屋看看、偷菜。中间的广场会随全镇总家产升级。 |
| 🛒 商店 | 种子、牲畜、土地（扩菜地 / 建牧场）、家具、庭院、车、房子、出售。 |
| 🏃 现实 | 钱从哪来：步数、少刷短视频的离线时间、今天从现实里赚了多少。 |
| 🔔 动态 | 朋友送礼、点赞、留言、来偷菜，只有真实的社交事件才推送。 |

## 主要规则

- **钱只从现实来**：每 1,000 步 🪙10 + 🪵1，6,000 步额外奖励和稀有种子；离线 30 分钟 / 1 小时 / 2 小时分别奖励，越久越多。木材只能从现实拿到，盖房子要用。
- **作物**：8 种，每种有 5 个阶段（刚种下、发芽、长叶、开花结果、成熟），长相都不一样，会随风摆动，成熟后闪光。不会枯萎。
- **牲畜**：鸡、兔子、绵羊、猪、奶牛、看家狗。幼崽、半大、成年三个阶段长相不同，会走动、啄食、跳、摇尾巴。成年后定时产鸡蛋 / 羊毛 / 松露 / 牛奶，隔几次下一只崽；牧场满了，崽先放仓库。农产品和崽都能卖钱。
- **偷菜**：去朋友家，成熟的菜上会出现 🖐，点一下顺走一点。每块地每人只能偷一次，最多偷到一半，主人总能留下大部分；每天最多偷 6 次。朋友家有看家狗时可能被赶跑（不扣任何东西）。朋友也会来偷你的，动态里能看到。
- **排行**：比的是家产（金币木材、房子、土地、家具装饰、车、牲畜、仓库），不比步数，运动数据永远不公开。全镇总家产决定小镇等级，是大家一起的目标。
- **每天 20 次农活**（种菜和偷菜算，收获、卖东西、买东西、设计都不算），用完弹出「今天的活干完了，去过你的生活吧」。
- **活力**只影响小人的精神状态（犯困、精神、蹦跳），不改变外观体型。小人可以选步行或轮椅。

## 文件

- `js/data.js`：所有数值和目录（作物、牲畜、家具、车、房子、价格、奖励），调平衡改这里
- `js/state.js`：游戏规则和存档
- `js/gfx.js`：等距绘图基础
- `js/sprites.js`：小人、作物、动物的画法
- `js/build.js`：房子、谷仓、篱笆、车、家具、庭院装饰、广场的画法
- `js/scene.js`：三个场景（家、室内、小镇）、相机、走动动画、点击、设计模式、商店缩略图
- `js/app.js`：界面、商店、弹窗、引导流程、原型控制台
- `js/i18n.js`：中文 / 英文文案
