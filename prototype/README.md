# 镜像小镇 · 交互原型

基于《产品概念：镜像小镇（暂定名）》第一版范围做的网页原型，用来演示核心循环和做用户访谈。不是正式的 iOS App。

## 打开方式

- 最简单：直接双击 `index.html`。
- 或者在 `D:\DreamWorld` 里运行 `python -m http.server 5173 --directory prototype`，然后打开 http://localhost:5173 。同一 Wi-Fi 下的手机可以用 `http://<电脑 IP>:5173` 打开，手机上会全屏显示，右上角 🛠 打开原型控制台。

进度存在浏览器本地（localStorage），控制台里的「重置原型」可以从头开始。

## 包含的内容（第一版范围）

| 文档里的功能 | 原型里怎么体现 |
| --- | --- |
| 资源来源：放下手机 | 控制台「离线 30 分钟 / 1 小时 / 2 小时」，离线越久奖励越多；「刷了 20 分钟」不扣任何东西 |
| 资源来源：步数 | 控制台「+1,000 步」；每 1,000 步得金币和木材，6,000 步得稀有种子；可选「休息日」 |
| 建造：房子 | 点自己的小屋：5 级房子、5 种装饰 |
| 建造：菜园 | 点菜地种菜，到时间自动成熟，不会枯萎 |
| 社交：邀请 / 拜访 / 送礼 | 「朋友」页、点朋友的房子；空地可邀请，控制台可模拟朋友接受邀请 |
| 设计原则 | 每天 10 次建造上限、只为真实社交事件推送、活力只影响精神不影响体型、目标完成状态默认不公开 |
| 小组件 | 控制台底部的锁屏小组件预览 |

## 文件

- `js/state.js`：游戏数据和规则（奖励数值、成本、每日上限都在这里调）
- `js/town.js`：等距视角小镇的绘制和触控
- `js/app.js`：界面、弹窗、引导流程、原型控制台
- `js/i18n.js`：中文 / 英文文案
