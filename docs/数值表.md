# 数值表（v0.40.0）

游戏里的全部内容和数值，从 `prototype/js/data.js` 自动生成。时间单位是分钟（现在为了演示用得很短，正式上线前要按真实节奏放大）。玩法说明见 `游戏设计.md`。

> 生成方式：数据在 `prototype/js/data.js`（游戏实际用的就是这份），运行 `node docs/生成数值表.js` 重新生成本文件。改数值只改 data.js。
