# 网页原型代码说明

`prototype/` 是网页版（v0.2.x）。Mason 认可它的 2.5D 画风，正式版沿用这个画风、在它的基础上完善（见 `决策记录.md` D19）。Swift 版如果选做法 A，这套画面代码会直接放进 iPhone App 里运行（见 `技术方案.md`）。

> 注意：原型用的是 `prototype/js/data.js` 里 v0.2 的内容和布局（8 种作物、14×12 的地）。正式版的内容和数值在 `docs/数值草案.js`（v0.3 草案，23 种作物、16×14 的地），两者不一样。

## 运行和测试

```bash
python -m http.server 5173 --directory prototype
```

打开 http://localhost:5173 。也可以直接双击 `prototype/index.html`。

- 屏幕宽度 ≤ 760px 时是全屏手机布局，更宽时显示手机外框和右侧的「原型控制台」。手机布局下点右上角 🛠 打开控制台。
- 控制台可以加步数、模拟离线、快进时间、模拟朋友互动和偷菜，还能直接 +🪙1000 试商店。
- 存档在浏览器 localStorage，键名 `mirror-town-proto-v2`。控制台「重置原型」清空。
- Claude 桌面 App 里用浏览器面板预览：配置在 `.claude/launch.json`（名字 `mirror-town-prototype`）。

## 文件和加载顺序

都是普通 `<script>`，按顺序加载，共享全局变量，没有打包步骤。

| 文件 | 内容 |
| --- | --- |
| `js/i18n.js` | 中英文文案 `STR`，`t(key, vars)` 翻译，`nm(item)` 取物品名，数字和时间格式化 |
| `js/data.js` | 所有内容和数值：作物、动物、农产品、土地、房子、家具、庭院、车、奖励、朋友预设、`VERSION` |
| `js/state.js` | 存档 `S` 和全部规则：种、收、偷、动物产出、买卖、摆放家具、资产排行、模拟朋友，没有 DOM 代码 |
| `js/gfx.js` | 等距投影 `iso()` / `unIso()`、颜色、基础图形（box、屋顶、墙面贴片）、夜晚灯光 |
| `js/sprites.js` | 小人（有手有脚、轮椅）、作物 5 个阶段、动物 3 个阶段的画法 |
| `js/build.js` | 房子、谷仓、篱笆、车、家具、庭院装饰、广场的画法 |
| `js/scene.js` | `Scene`：三个场景（家、室内、小镇）、相机、走动动画、点击、设计模式、商店缩略图 |
| `js/app.js` | 界面：顶栏、页签、场景上的按钮、商店、弹窗、引导、控制台；`ACT` 是所有按钮动作 |

## 存档结构 `S`

```js
S = {
  v: 2, lang: 'zh' | 'en', apps: [...], limitMin, timeOffset,  // timeOffset：控制台快进的时间
  me: Home, friends: [Home...],
  slots: [{ c, r, owner }],          // 小镇 3×3 格，中间是广场
  today: { steps, focusMin, actions, steals, goalPaid, restDay, liked, earned, ... },
  pending: [...],                    // 现实奖励，等玩家领取
  feed: [...],                       // 动态（礼物、点赞、留言、被偷……）
}
Home = {
  id, name, look: { shirt, skin, hair, hairCol, mob: 'walk' | 'wheel' },
  coins, wood, house, wall, roof,
  room: { wall, floor, items: [{ id, k, x, y, rot, tint }] },
  yard: [{ id, k, x, y, rot }], store: { 'room:sofa': 1, ... },
  fieldLv, fields: [{ crop, at, left, thieves } | null],
  pastureLv, animals: [{ id, k, born, last, cycles }],
  cars: [{ k, color }], car, seeds: {}, barn: {}, likes, shareGoal, goalToday,
}
```

- 所有游戏时间都走 `now()`（= 真实时间 + `S.timeOffset`）。
- 朋友的家和你的家结构一样，所以画法、排行、拜访都通用。`simFriends()` 每 5 个模拟分钟让朋友赚点钱、收菜、偶尔买东西。

## 坐标和画面

- 等距格子：`TW = 64`、`TH = 32`。x 往右下，y 往左下。家园地 `LOT_W × LOT_D`，马路在 y = `LOT_D` 外面。区域划分见 `AREA`。
- 远近排序：每个物体有深度 `d`（大致等于中心的 x + y），从小到大画。
- 小镇：每块地放在 `SLOTS` 的格子里，原点是 `(c × SLOT_W, r × SLOT_D)`。
- 夜晚：`nightAmount(now())` 决定暗度，窗户和灯会亮。

## 点击和界面

- `Scene.init(canvas, onSceneHit)`：画面上的点击回调到 `app.js` 的 `onSceneHit(h)`，`h.kind` 有 `field`、`steal`、`animal`、`collect`、`house`、`car`、`avatar`、`lot`、`place`（设计模式）等。
- 页面按钮都写成 `data-act="名字" data-arg="参数"`，点击后执行 `ACT[名字](参数)`，然后 `refresh()` 重画界面。
- 弹窗：`openSheet(type, arg)`，内容在 `SHEETS` 里。

## 加内容的方法

| 加什么 | 改哪里 |
| --- | --- |
| 作物 | `data.js` 的 `CROPS` + `sprites.js` 的 `PLANTS` 里写一个画法（阶段 2–4） |
| 动物 | `ANIMALS` + `ANIMAL_DRAW` 画法 + `ANIM_SHADOW` 影子大小 + `scene.js` 的 `SPEED` |
| 家具 | `FURN` + `build.js` 的 `drawFurn` 里加一个 `case` |
| 庭院装饰 | `YARD` + `drawYardItem` 里加一个 `case` |
| 车 | `CARS` + `CAR_SPEC`（普通汽车）或单独的画法函数 |
| 房子 | `HOUSES` + `drawHouse` 里加一个分支 |
| 文案 | `i18n.js` 的 `STR.zh` 和 `STR.en` 两边都要加 |

## 调试用的入口（在浏览器控制台里用）

```js
Scene.look(2, 6, 7)   // 缩放到 2 倍，看世界坐标 (6, 7)
Scene.bench(20)       // 连画 20 帧，返回每帧毫秒数
Scene.debug()         // 当前相机、场景、设计模式状态
```

快速走完入住引导（测试时用）：

```js
document.querySelector('[data-act=obLang][data-arg=zh]').click();
document.querySelector('[data-act=obNext]').click();
const i = document.querySelector('#obName'); i.value = 'Mason'; i.dispatchEvent(new Event('input', { bubbles: true }));
document.querySelector('[data-act=obNext]').click();
document.querySelector('[data-act=obDone]').click();
```

## 容易踩的坑

- **浏览器缓存旧文件**：改了 JS 或 CSS 后，把 `index.html` 里所有 `?v=数字` 加一。临时绕过可以在页面里执行 `fetch('js/app.js?v=当前数字', { cache: 'reload' })` 再刷新。
- **浏览器面板截图有时是上一帧**：操作后连拍两张，用第二张。
- **布局变了，旧存档里的庭院物品可能压在新区域上**：`load()` 里的 `fixLayout()` 会自动把它们挪走。
- **Claude 桌面 App 的文件预览**用 `data:` 地址打开 `index.html`，脚本加载不了，只显示一个 🛠 按钮。要用 http://localhost:5173 预览。
- 中英文要两边都检查：可以临时替换 `window.t` 记录找不到的键，把所有面板和弹窗渲染一遍。
