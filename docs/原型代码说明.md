# 网页版代码说明

`prototype/` 是游戏本体（v0.3.0 起）：画面、玩法、界面都在这里。iPhone App（`ios/`，Swift）把整个文件夹打包进去，在全屏网页视图里运行，Swift 只负责读 Apple 健康并通过 JS 桥交给游戏（见 `技术方案.md`、`ios/README.md`）。

所以：**改游戏 = 改 `prototype/`**。在这台 Windows 电脑上改完、用浏览器手机尺寸测好，推到 GitHub；Mason 在 Mac 上拉下来重新运行 Xcode 就是新版。

## 运行和测试

```bash
python -m http.server 5173 --directory prototype
```

打开 http://localhost:5173 。也可以直接双击 `prototype/index.html`。

- 屏幕宽度 ≤ 760px 时是全屏手机布局，更宽时显示手机外框和右侧的「原型控制台」。手机布局下点右上角 🛠 打开控制台。
- 控制台：换昨晚睡眠分（看表情、动作、倍率变化）、开始 / 结束一次 Apple Watch 训练（迷你的你）、加步数 / 千卡 / 锻炼分钟 / 站立小时 / 正念、模拟离线、快进时间、下一天、朋友互动 / 偷东西 / 寄信 / 开始运动 / 入住、+🪙1000。
- 存档在 localStorage，键名 `mirror-town-proto-v3`（存档结构 `S.v === 3`）。v0.3 的存档会被 `migrate()` 补上 v0.4 的字段（楼层、隐私开关、纪念品、个人目标），老玩家不看新手引导。想从开屏重新体验：控制台最下面「重新开始」。
- Claude 桌面 App 的浏览器面板预览：`.claude/launch.json` 里的 `mirror-town-prototype`（端口 5173）。
- **测试小技巧**：浏览器面板被隐藏时，requestAnimationFrame 会停，小人看起来卡住不动。用 `Scene.bench(n)` 手动渲染 n 帧（每帧 16 毫秒）推进动画和走路；`Scene.debug()` 看小人位置、任务、姿势；`Scene.look(z, x, y)` 把镜头放到世界坐标。

## 世界、地和天气（v0.6）

- **数据**（`data.js`）：`STREETS`（每条街：社区、左上角、几块地）、`ROADS`（矩形：街道 / 大道 / 土路）、`LANDMARKS`（广场、商店、公园、湖、麦田）、`NPC_LOTS`（其他居民的位置和房子）、`START_LOTS`（你和朋友开始住哪）、`LAND`（地价）。
- **谁住哪**（`state.js`）：`S.lots = [{ id, st, p, n, paid }]`（你和朋友；`p` 是第几块地，`n` 是几块）。`lotOrigin(id)`、`lotW(id) / homeW(h)` 给出位置和宽度；`vacantRuns()` 是所有空地（有缓存）；`buyParcel()` 买右边一块；`relocate(st, p)` 搬家；`freeRun()` 给新朋友找地（尽量不占你右边）。旧存档的 `S.slots` 在 `migrate()` 里换成 `S.lots`。
- **其他居民**：`genNPCs()` 每次读档时按固定种子生成 `NPCS`（不存档）；`homeOf(id)` 也能找到他们；`isFriend(id)` 区分好友和陌生人（陌生人不能偷、不进排行）。
- **画世界**（`scene.js` 的 `renderWorld`）：地面 → 湖、公园、麦田、路、镇中心 → 树林（`scenery()` 只算一次）→ 空地（虚线和「出售」牌）→ 每户人家 → 天气地面效果 → 按深度画所有东西 → 天气空中效果 → 夜色 → 标签。`far()`（镜头很远）时房子用 `drawHouseFar`，不画动物、人和栅栏。
- **院子宽度**：`yardReserved(x, y, w)`、`yardSpots(w)`、`lotNav`、`lotGround`、`fenceObjs` 都按这户的宽度来。
- **天气**：`weatherNow()` = 控制台强制的 > 真实天气（3 小时内）> `simWeather()`；`weatherGround / weatherSky` 画效果；`rainGrow` 下雨时让菜长得快；`app.js` 的 `realWeather()` 用 `navigator.geolocation` + Open-Meteo（坐标取一位小数）。

## 世界和坐标（`scene.js`，v0.3 的说明，部分已被上面取代）

- 一个世界：3 × 3 个地块（每块 `LOT_W × LOT_D` = 16 × 14 格，前面是 2 格宽的马路，右边 1 格人行道），中间那块 `PLAZA` 是镇政府广场。四周 16 格树林，左下有个湖（`LAKE`）。最下面那条马路一直通到树林外。
- 每个家的地块左上角：`lotOrigin(id)` → `[c * SLOT_W, r * SLOT_D]`。地块里的东西用「地块内坐标」，画的时候加上地块原点。
- 三种视角（`Scene.setView(mode, owner)`）：
  - `home`：镜头对准某个地块（自己的或正在拜访的朋友的），周围邻居、马路、树林照样画，看不见的地块不画。
  - `town`：镜头拉远看整条街，地块上方是名字、名次、家产标签。
  - `interior`：屋里，房间大小由房子决定（`HOUSES[i].room`）。
- 切换视角时镜头会「飞」过去（`flyTo`）。拖动、双指 / 滚轮缩放；镜头不会拖出世界。
- 画法：所有东西放进 `objs`，按深度（x + y）排序后画（画家算法）。缩得很小（`cam.z < 0.34`）时地块用简化画法，树林用简化的树。

## 开屏和新手引导（`app.js` 末尾）

- 第一次打开（没有存档）时，`newGame({ preview: true })` 先把游戏建好（`S.onboarding = true`），开屏浮在真实小镇上面。`body.ob-mode` 会藏起顶栏、标签栏和场景按钮。
- 开屏 6 屏（`OB.step`）：0 标题和开始按钮；1–3 图片故事（`Scene.thumb('story', k)` 每帧画动画）；4 捏小人（`Scene.focusMe` 镜头对准小人，改了马上在小镇里看到）；5 选分心 App。开屏时镜头用 `Scene.attract(z)` 在街上慢慢转，不画名字标签。
- 「入住小镇」（`obDone`）把名字、外观、App 写进存档，`S.onboarding = false`，`S.tut = 0` 开始新手引导。中途刷新会回到开屏第一屏（存档还在）。
- 新手引导 `TUT`：每步有目标位置（`sceneAt` 用 `Scene.where` 算场景里的位置，`domAt` 找按钮）和可选的 `skip`。真正做了那件事时，对应的地方调用 `tutDone(id)` 进下一步（走路在 `onSceneHit`，收割在 `harvestField`，领取在 `collectAll`，种菜在 `plant`，切标签在 `setTab`）。`#coach` 画光圈、手指和一句话；打开弹窗或设计模式时自动藏起。`S.tut = -1` 表示结束（跳过也是）。结束后才送欢迎礼物和信（`welcomeGifts`）。

## 楼层（`state.js` + `scene.js`）

- 每层是一个房间 `{ wall, floor, items }`：一楼是 `h.room`，楼上是 `h.ups[0]`、`h.ups[1]`……；每套房子盖了几层存在 `h.extra[房子编号]`。`floorsOf(h)` = 自带层数 + 加盖层数。
- `LEVEL`（state.js 的全局变量）是屋里正在看的那层，出门、进门、拜访时回到 0。`curRoom(h)` 给你自己家当前这层（家具摆放、设计模式、墙纸地板都用它）；`scopeItems / canPlace / autoPlace` 都带可选的层号参数，朋友家模拟买家具固定放一楼。
- 楼梯 `stairsRect(h)` 固定在右后角（2×1 格），有两层以上时不能摆家具、不能走。`fitRooms(h)` 在加盖、搬家、读存档时把放不下的家具（超出房间、挡楼梯、这套房子没有的楼层）收进仓库。
- 屋里：`renderInterior` 画当前层；一楼左墙是门，楼上是窗；`drawStairs` 画上楼的楼梯或顶层的楼梯口，点它（`kind: 'stairs'`）上下楼。`app.js` 的 `ACT.floor(i)` 让小人先走到楼梯（`Scene.go({ kind: 'stairs' })`）再 `switchFloor`。
- 外面：`build.js` 的 `drawHouse` 按加盖层数把墙加高、多画几排窗（`storyRows`）；现代别墅多叠几个上层，中式庭院画成楼阁，城堡的塔也一起长高。

## v0.5 的手感和画面

- **朝向**：`stepAlong` 按走的方向设 `face`（屏幕左右）和 `back`（往屏幕上方走 = 背对镜头）；`arrive` 时回到正面（或 spot 的第 4 个值）。`drawPerson(..., { back })` 画后脑勺（`backHead`）。
- **高清**：`Scene.thumb` 按 `devicePixelRatio`（2–3 倍）画；头像用 `THUMB.face`（头肩像），`avatar(look, cls, energy)`。
- **楼梯**：`stairsRects(h, lv)` 给出这一层的「上楼楼梯」（右后角）和「下楼楼梯口」（它左边）。`Scene.takeStairs(dir, onSwitch, onArrive)`：小人走到楼梯前 → `meIn.anim` 沿楼梯走并改变高度（`lift`）、淡出 → `onSwitch` 换层 → `arriveStairs` 从另一层的楼梯口冒上来或从楼梯上走下来。下到楼梯口时用裁剪把地板以下的身体藏起来。`app.js` 的 `ACT.floor(i)` 一层层走。
- **家具必须走得到**：`roomReachable(h, lv, items)` 从门口（楼上是楼梯口前）出发，检查每件家具旁边和楼梯前都能走到；`canPlace` 对房间家具都会检查，放不下时 `PLACE_WHY = 'block'`（提示「会挡住路」）。`roomSpots` 先给四面墙边的格子。
- **阴影**：屋里 `furnShadow`，院子在 `lotGround` 末尾（花草树木不画）。
- **小标签**：点家具 / 庭院装饰时 `tip(kind, k, name, sub)` 在点的位置上方显示（`Scene.tapAt()` 给出最后一次点击的位置）。
- **商店二级分类**：`data.js` 的 `SHOP_SUBS`，`app.js` 的 `curSub / subChips`，选中的小类存在 `UI.sub[大类]`。

## v0.7 的画面和声音

- **字体**：`prototype/fonts/` 里的字体由 `tools/make_fonts.py` 生成：它扫描 `prototype/` 里 js / html 用到的汉字（「游戏用字」）和最常用的 3755 个汉字（GB2312 一级字），从 `tools/font-src/`（不进仓库，放原始字体 Nunito 和 Resource Han Rounded 的 ttf）裁出子集、改名、写 `fonts.css`（`unicode-range`，浏览器只下载用到的那份）。**加了新的中文文字后要重新运行**：`python tools/make_fonts.py`（要装 `fonttools` 和 `brotli`）。源字体缺失时先从 Google Fonts（Nunito）和 GitHub 的 CyanoHao/Resource-Han-Rounded 下载。
- **前后走路**：`faceTo(a, dx, dy)` 设 `face / back / view`；上下方向为主时 `view = 'front' / 'back'`，`sprites.js` 的 `drawPersonFront` 画正面 / 背面走路。
- **缩小时的房子**：`drawHouseCached` 把房子按缩放档位（1.15 倍一档）和晚上 / 白天画进离屏画布 `HOUSE_SPR`，之后直接贴图；灯光另外画。`cam.z < 0.42` 时用。远看的菜地 `cropRows`、树冠、雪山 `mountains`、小河 `river` 都在 `renderWorld`。
- **缩放范围**：`minWorldZoom()` = 整个世界刚好装满屏幕；`clampCam` 管住镜头。注意 `Scene.look()` 不经过这个限制，测试缩放要用滚轮事件（`zoomAt`）。
- **楼梯**：`stairsRects(h, lv)`：`up` 在 `(rw-2, 0)` 2×1，从 `(rw-3, 0)` 踏上；`down` 在 `(rw-2, 1)` 2×1，从 `(rw-1, 2)` 走进。`stepAnim` 里 `flight` 让小人按 7 级台阶升高（`STAIR_H`），`clip` 进楼梯口时裁掉地板以下。
- **坐和躺**：`SEAT_H`（每种座椅屁股的高度，骨架 `sit` 用 `o.seatH` 让脚着地）、`LIE_H`（床垫高度）、`LIE_HEAD`（头在枕头上的位置），`useSpot` 算位置，`lieDir` 让头朝床头，躺下后 `drawBedQuilt` 再画一次被子盖上。寻路 `bfsFrom` 允许从自己所在的家具里走出来。
- **车**：跑车 / 肌肉车 / 超跑在 `CAR_SPEC` 里有 `sleek`，由 `build.js` 的 `drawSleekCar` 画（`slope()` 画斜面的车身和车窗）。
- **声音钩子**：`app.js` 里收获、种菜、买、领取、开门、写信、加盖、纪念品、偷、狗叫都调 `Sound.play`；设置开关存 `S.music / S.sfx`。

## 隐私、安静模式、纪念品

- 每家有 `shareGoal / shareLive / shareMood` 三个开关（你自己的默认全关）。`seesGoal(h)`、`seesLive(h)`、`friendEnergy(h)` 统一判断能看到朋友的什么；`S.calm` 是安静模式（不显示排行和名次、朋友的运动和精力、动态里的「完成目标」）。
- 纪念品是 `FURN` 里 `souv: true` 的家具（商店不卖）。`S.stats` 记录天数、达标天数、连续睡好、三环、离线 2 小时、正念分钟、运动次数；`refresh()` 里 `awardSouvenirs()` 发新纪念品，自动摆进一楼，`UI.souvQ` 排队弹出「新纪念品！」。

## 小人操控（`scene.js`）

- 你的小人（`me`，在 `me.lot` 那块地上）**从不自己乱跑**，只听指挥。屋里是另一个 `meIn`。
- 寻路：每块地一张 17 × 16 的格子图（含门前马路），房子、谷仓、果树、鱼塘、庭院装饰、车、邮箱不能走；地块的栅栏只在小路（x = 3）和车道（x = 0–1）开口；牧场栅栏只有左边最下面一格是门。BFS 找路，再把能直走的折线拉直。
- 任务：`Scene.go(target, {pose, dur, sneak, done, valid})` 把一件事排进队列：小人走到目标旁边（`spotFor` 决定站哪、朝哪），摆姿势 `dur` 毫秒，然后执行 `done`（真正改存档的是 `app.js` 传进来的 `done`）。`Scene.goMany(list)` 按最近的顺序排一串（一键收获、全种上）。点空地会取消队列直接走过去；「停下」按钮 = `Scene.cancel()`。
- 目标种类：`ground`、`field`、`animal`（动物会停下等你）、`tree`、`yard`（蜂箱）、`pond`、`mailbox`、`door`、`gate`；屋里 `furn`（坐下 / 跑步机 / 动感单车 / 举铁 / 沙袋 / 瑜伽垫）、`floor`、`exit`。
- 偷东西：`sneak: true` 时小人弯腰踮脚慢慢走；被看家狗发现时 `Scene.flee(dogId)`，小人跑到门前马路，狗追一段。罚款在 `state.js` 的 `caught(fid, value)`（`dogFine` = 价值 × 2，限制在 `STEAL_FINE`），`S.today.chased[fid]` 记住当天被哪家赶出来，`sneakCheck(fid)` 和 `app.js` 的 `sneakDo` 会拦住。
- 小人走出屏幕边缘时镜头会跟着挪一点。

## 迷你的你（`scene.js` 的 `doLive`）

`S.live = {type, start, hr}` 存在时（控制台或 iPhone 的 `onNativeWorkout` 设置），小人放下手上的事，同步运动：

| 运动 | 小人 |
| --- | --- |
| 跑步 / 步行 / 骑车 / 轮椅 | 走出院门，在门前马路上来回跑 / 走 / 骑 |
| 游泳 | 自家有鱼塘就在鱼塘游，有泳池在泳池，都没有就去树林里的湖 |
| 力量、瑜伽、高强度间歇、舞蹈 | 在房子门前空地上举铁、瑜伽、开合跳、跳舞 |
| 在屋里 | 有对应器材就用（跑步机、动感单车、哑铃架、沙袋、瑜伽垫） |

头顶显示「运动图标 分钟 ❤️心率」，镜头自动跟着小人（拖动后停止跟随，点「回中间」恢复）。朋友公开了运动时（`shareGoal`），他们也会这样运动，只显示运动图标。

## 规则要点（`state.js`）

- 时间都走 `now()`（真实时间 + 控制台快进的 `S.timeOffset`）。生长时间在 `data.js` 里用**分钟**写（演示用，正式上线前放大），用的时候乘 `MIN`。
- 精力：`energyScore()` = 睡眠分（`S.sleep.score`，没有就自己用睡眠阶段算 `sleepScore`）+ 正念（最多 +5）；`energyLevel()` → `great / good / tired / exhausted`；`energyMult()` 是运动奖励倍率（休息日不打折）。
- 健康奖励：`processHealth()` 把今天新达成的进度变成「待领取」（步数每走到目标的 1/6、步数目标、三个环、三环全合、10 分钟以上的训练、正念、睡眠 80+），重复调用不会重复发。步数目标 `stepGoal()` 在 `checkDay()` 里按最近 7 天平均更新；步数最多算 `STEP_BLOCKS_MAX` 次，运动每天最多算 `WORKOUT_PAY_MAX` 分钟。
- iPhone 数据：`applyNative(d)` 只会把今天的数字往上调，不会往下改；有真实数据后（`S.native`）不再模拟睡眠。
- 偷：每人每块地 / 每只动物 / 每棵树只能偷一次，主人至少留一半（`stealKeep`），每天最多 `STEAL_CAP` 次，占农活次数；成年看家狗 35% 机会抓到人（罚款见上面「小人操控」）。
- 房子：`S.me.houses` 是买过的所有房子，`S.me.house` 是正在住的；搬家家具和院子跟着走。

## JS 桥（`app.js` 末尾）

- 网页 → Swift：`postNative({type: 'ready'})`（启动后），`postNative({type: 'refresh'})`（打开健康页）。
- Swift → 网页：`window.onNativeHealth(json)`、`window.onNativeWorkout(json)`。字段见 `ios/README.md`。

## 常见改动

- **加一种作物 / 动物 / 家具 / 庭院 / 载具 / 房子**：先在 `data.js` 加数据（名字中英文、价格等），再在 `sprites.js`（作物 `PLANTS`、动物 `ANIMAL_DRAW`）或 `build.js`（家具 `drawFurn` / `drawFurn2`、庭院 `drawYardItem` / `drawYard2`、载具 `CAR_SPEC` / `drawTwoWheeler`、房子 `drawHouse`）加画法。商店会自动列出来。然后 `node docs/生成数值表.js`。
- **加界面文字**：`i18n.js` 里中英文都要加同一个键（v0.4 新加的键集中在 `STR` 后面的 `Object.assign` 里）。
- **加纪念品**：`data.js` 的 `FURN` 加一件 `souv: true, price: 0`，`SOUVENIRS` 加条件（`need` 是 `S.stats` 里的计数）；新的计数要在 `state.js` 里累加；`build.js` 的 `drawFurn2` 加画法；`i18n.js` 加 `souv_need_计数名`。
- **改数值**：只改 `data.js`，再重新生成数值表。
