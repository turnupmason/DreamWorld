# 镜像小镇 · 游戏设计（v0.4）

> 现实里的你，决定游戏里那个迷你的你过得怎么样。

这份文档汇总了目前定下来的全部玩法和内容。游戏本体是网页版（`prototype/`），已经实现了这里的大部分内容（操控小人、偷菜偷蛋、邮箱、精力、迷你的你、全部作物动物家具载具房子；v0.4.0 加了开屏和新手引导、隐私和安静模式、纪念品、多层楼）；iPhone App（`ios/`）把它装进去并读 Apple 健康。还没做的：屏幕使用时间真实读取、Apple Watch App、多人服务器、学习卡片、季节和小镇共建。

- **为什么玩、卖点、玩到最后玩什么、不运动的人怎么玩、怎么避免压力**：见 `核心设计.md`（先读这份）。
- 全部内容的具体数值见 `数值表.md`（数据在 `prototype/js/data.js`，时间暂时用分钟方便演示，见决策 D26）。
- 商业模式、验证计划、留存目标、风险见 `产品概念.md`。
- 每条玩法从哪个需求来、为什么这样定，见 `需求记录.md` 和 `决策记录.md`。

## 核心循环

现实里运动、睡好、少刷短视频 → 得到金币、木材、种子 → 种地、养殖、钓鱼、摘果子，卖了赚更多 → 买地、盖房、买车、买家具，把家布置成自己喜欢的样子 → 和朋友住一条街：拜访、点赞、送礼、写信、偷菜 → 家产排行，全镇一起升级。

**钱只从现实来**：金币和木材最初都来自运动和少刷手机。农场能让钱变多，但木材只能从现实拿到，盖大房子必须靠现实。

## 一、现实数据怎么进游戏

### 数据来源

| 来源 | 能拿到的数据 | 接入方式 |
| --- | --- | --- |
| Apple Watch / iPhone（Apple 健康） | 步数、活动三环（活动 / 锻炼 / 站立）、体能训练、睡眠阶段、呼吸频率、心率、静息心率、心率变异性（HRV）、正念和呼吸练习、轮椅推动次数 | HealthKit |
| Oura Ring | 睡眠分、准备度（Readiness）、HRV、体温偏差 | 写进 Apple 健康的部分走 HealthKit；准备度和睡眠分走 Oura 官方 API |
| Whoop | 恢复度（Recovery）、劳累度（Strain）、睡眠表现 | 写进 Apple 健康的部分走 HealthKit；恢复度和劳累度走 Whoop 官方 API |
| 其他能写进 Apple 健康的设备（Garmin 等） | 同上 | HealthKit |
| 屏幕使用时间 | 用户选定的分心 App 用了多久 | Family Controls / DeviceActivity |

### 精力：睡眠决定今天的状态

每天早上算一次精力分（0–100），按这个顺序取第一个有的：Whoop 恢复度 → Oura 准备度 → Apple 睡眠分（如果苹果开放读取）→ 我们自己用睡眠阶段算的睡眠分。当天做了正念或呼吸练习，精力最多再加 5 分。

| 精力 | 分数 | 小人的表情和动作 | 运动奖励倍率 |
| --- | --- | --- | --- |
| 满格 | 85+ | 大笑、身上闪光、走路蹦蹦跳跳 | ×1.3 |
| 不错 | 70–84 | 微笑、正常走 | ×1.0 |
| 有点累 | 50–69 | 半睁眼、偶尔打哈欠、走得慢 | ×0.75 |
| 很累 | 50 以下 | 黑眼圈、头顶冒 z、低头慢慢走 | ×0.5 |

- 倍率只算在运动类奖励上（步数、三环、体能训练）。少刷手机的奖励不打折。
- 精力只改变表情和动作，不改变外观和体型。
- **设计提醒**：这一条改了最初「奖励永不惩罚」的原则。失眠、带娃、倒班的用户可能会觉得被惩罚。建议保留「休息日 / 生病」按钮：当天目标奖励照发、不打折；连续几天睡不好时，小人给出关心的话，而不是只显示打折。

我们自己的睡眠分（没有 Whoop / Oura / 苹果睡眠分时用）：

- 时长 50 分：睡够 7–9 小时满分，不足按比例扣。
- 质量 30 分：深睡 + REM 占睡眠的 40% 以上满分。
- 中断 20 分：夜里清醒每 3 分钟扣 1 分。

### 奖励表（按「不错」精力 ×1.0 列）

| 现实里做到 | 奖励 |
| --- | --- |
| 每走到自己目标的 1/6（目标 6,000 时 = 每 1,000 步；轮椅推动也算），最多算到目标的 150% | 🪙10 🪵1 |
| 走到自己的步数目标 | 🪙20 🪵3 + 南瓜种子 |
| 合上活动环（默认 500 千卡） | 🪙25 🪵3 |
| 合上锻炼环（30 分钟） | 🪙25 🪵3 |
| 合上站立环（12 小时） | 🪙15 🪵2 |
| 三环全合上 | 再加 🪙40 🪵5 + 玫瑰种子 |
| 每次 10 分钟以上的体能训练 | 每分钟 🪙1.2，每 10 分钟 🪵1（每天最多算 90 分钟） |
| 正念 / 呼吸练习 | 每分钟 🪙5（每天最多 10 分钟），精力 +1 |
| 睡眠分 80+ | 早上 🪙20 + 郁金香种子 |
| 离线 30 分钟 / 1 小时 / 2 小时 | 🪙15 🪵2 / 🪙35 🪵5 / 🪙80 🪵12 + 向日葵种子 |
| 刷超了 | 不扣任何东西 |

**步数目标跟着自己走**（D28）：开始是 6,000 步，之后 = 最近 7 天平均 × 1.1，取整到 500，在 3,000–12,000 之间。走 3,000 步的人和走 12,000 步的人，走到自己的目标拿到的一样多。

### 纪念品：钱买不到的东西（D32）

纪念品是一种特别的家具，商店里看得到但买不到，只能在现实里做到：

| 纪念品 | 怎么得到 |
| --- | --- |
| 一周日历 | 来小镇 7 天（休息日也算） |
| 跑鞋架 | 3 天走到自己的步数目标 |
| 月亮夜灯 | 连续 3 晚睡眠 80 分以上 |
| 三环奖牌 | 合上一次三个圆环 |
| 读书角 | 一次离开分心 App 2 小时 |
| 小盆景 | 正念累计 30 分钟 |
| 运动奖杯 | 10 次 10 分钟以上的运动 |

拿到时弹出「新纪念品！」，自动摆进一楼；不计入家产。商店「家具」和健康页都能看到进度。

### 学习卡片（概念 PDF 原有，排在「持续扩展」阶段）

30 秒知识卡片（冷知识、英语表达、历史故事），学完得稀有种子或家具。第一版不做，按内测数据决定什么时候加。

### 屏幕使用时间的限制

苹果的屏幕使用时间接口拿不到精确分钟数，只能按「达到某个时长」这类阈值触发；用户在系统的 App 选择器里自选分心 App，我们看不到具体选了什么。所以少刷奖励按阈值设计（离线 30 分钟 / 1 小时 / 2 小时，分心 App 用到上限时提醒但不扣东西）。

### 迷你的你：运动实时同步

在 Apple Watch 上开始一种运动，游戏里的小人同步做同样的事，头顶显示「运动类型 · 已运动时长 · 心率」：

| 运动 | 小人在做什么 |
| --- | --- |
| 户外步行 / 跑步 | 沿着院子小路和街道走 / 跑 |
| 骑车 | 骑上自己的自行车绕街 |
| 游泳 | 在鱼塘或泳池里游（没有就去镇上游泳馆，显示在门口） |
| 力量训练 | 举哑铃 |
| 瑜伽 | 在瑜伽垫上做体式 |
| 高强度间歇 | 开合跳 |
| 舞蹈 | 跳舞 |
| 轮椅运动 | 推着轮椅绕圈 |

- 锁屏和灵动岛用实时活动（Live Activity）显示小人正在跑。
- 运动结束后结算奖励，朋友可以给你加油（点赞）。
- **技术前提**：真正的实时同步需要我们自己的 Apple Watch App 来开启运动，数据实时镜像到手机。用户用苹果自带的「体能训练」App 运动时，其他 App 拿不到实时数据，只能等运动结束、数据存进健康以后再显示。

## 新手的第一分钟（D34）

- 开屏：背后是真实的小镇在慢慢转，前面只有标题、一句话、一个「开始」按钮。
- 3 张图片故事，每张一句话（睡得好小人就精神 / 动一动就有金币木材 / 种地盖房和朋友做邻居），可以跳过。
- 捏小人：镜头对准自己的小人，改了马上看到。
- 选分心 App 和每天上限。
- 进游戏后手指引导 6 步：点地面走过去 → 点熟了的小麦收割 → 领取现实奖励（入住礼包）→ 在空地种菜 → 去看小镇 → 看健康页。每步一句话，做了才进下一步，随时可以跳过。引导结束后两个邻居送来礼物和一封欢迎信。

## 二、操控小人

小人由玩家操控，所有动作都要走过去做，不会自己乱跑然后东西就收好了：

- 点地面：走过去。
- 点空菜地：选种子 → 小人走过去 → 蹲下种。点成熟的菜：走过去 → 蹲下收，菜飞进篮子。
- 点动物：走进牧场 → 蹲下捡蛋 / 挤奶 / 剪羊毛 / 抱起幼崽。
- 点果树：摘果子。点鱼塘：甩竿钓鱼。点蜂箱：取蜂蜜。
- 一键收获：小人按顺序一块一块走过去收，不是瞬间完成。
- 屋里点家具就去用：坐沙发（屁股在座位上、脚踩地）、躺床（头枕枕头、盖被子）、跑步机上跑、骑动感单车、举哑铃、打沙袋、做瑜伽、弹钢琴、弹吉他。
- 去朋友家：偷菜、偷蛋 / 奶 / 果子。蹑手蹑脚走过去；有看家狗时可能被抓到（D54）：赔主人想偷的东西价值的 2 倍（🪙10–60），被狗追出院子，当天不能再偷这家。
- 其他住户（朋友）的小人由他们自己现实里的状态驱动，在自己家里活动。

## 三、邮箱和信

- 每家门口都有邮箱，有新信时小红旗竖起来。
- 写信：选朋友、选信纸、写字（最多 200 字），可以附一份礼物（农产品、金币、木材）。
- 寄出：小人走到邮箱投进去，邮差把信送到朋友家邮箱。
- 收到回信会推送通知（这是真实的社交事件）。

### 家具怎么摆（D40）

- 必须让小人走得到：从大门（楼上是楼梯口）能走到每件家具旁边和楼梯前，挡路的摆不下。
- 买来自动摆放时先沿四面墙摆，中间留出走路的地方；地毯可以垫在家具下面。
- 家具和院子里的装饰都有落地阴影。

### 多层楼（D33）

- 每种房子有自带层数和最多层数：帐篷 1 层；小木屋最多 2 层；小平房、中式庭院最多 3 层；两层小楼、花园别墅最多 4 层；现代别墅、豪宅最多 5 层；城堡最多 6 层。
- 加盖一层的价格 = 室内格数 × 🪙40 / 🪵0.8，每多一层 ×1.5（具体见 `数值表.md`）。在商店「房子」顶上、或屋里顶栏的「＋」加盖。
- 每层是独立房间：自己的墙纸（12 种）、地板（8 种）、家具。在哪层买家具就摆在哪层，设计模式只改当前这层。
- 楼梯（D51）：上楼的楼梯沿后墙、在右后角往右升高；下楼的楼梯口在它正前方。点楼梯或顶栏的「1F / 2F / 3F」，小人走过去一级一级踩着台阶上去，到了楼上从楼梯口冒上来；下楼是走进楼梯口慢慢沉下去，到了楼下从楼梯上一级级走下来。只有一楼有大门，楼上那面墙是窗户。
- 外面看，房子随层数长高：多数房子多一排窗；现代别墅一层层往上叠；中式庭院变成多层楼阁。
- 搬去层数少的房子时，放不下的家具收进仓库；搬回来时已经盖的楼层还在。去朋友家也可以上楼看看。

## 五、小镇世界（D42–D46）

- **地图**：梧桐街社区（梧桐街、樱桃巷）、田园（麦田路、草场路）、湖畔（望湖路、湖滨大道），中间是镇中心（镇政府广场、面包店、咖啡馆、超市、健身房、图书馆、邮局）和森林公园（池塘、足球场、游乐场），东边是镜湖（码头、小船），南边是麦田（谷仓、风车），四周是树林。街道、三车道大道、土路宽窄不同。
- **地**：每条街分成 4 格宽的一块块地。一个家占 4 块（16 格宽），右边的空地可以一块块买下，每块贵 35%，社区不同地价不同（湖畔贵、田园便宜）。买来的地先当院子用。
- **搬家**：点任何一块够大的空地，可以把整个家搬过去；之前买的地退一半。
- **其他居民**：镇上住着 9 户不是好友的居民，房子、地的大小、农场都不一样；可以串门、进屋看，不能偷他们的菜。
- **天气**：晴、多云、雨、雪、雾、雷雨，有雨丝、雪花、积雪、云影、雾气、闪电；下雨时菜长快 25%。打开「真实天气」后用所在地区的天气（只用约 10 公里的大概位置，不保存），否则用小镇自己的天气。
- **远看**（D48、D50）：缩小时房子永远是完整的房子，菜地看得到一行行庄稼，树林是一团团树冠；最多缩到整个世界装满屏幕，四周是雪山和流进镜湖的小河；字跟着缩放变小。
- **声音**（D53）：轻柔的八音盒背景音乐（白天轻快、晚上慢），干活、买东西、开门、上楼、狗叫都有音效；晴天鸟叫、下雨有雨声、打雷有雷声。第一次点屏幕后开始，设置里可以分别关掉音乐和音效。

## 六、街道和社交

- 5–10 个朋友住一条街，每人一块地。家旁边就是邻居家、马路、广场和树林，不是悬空的一块板。
- 拜访朋友家：看他们的房子、牲畜、车，进屋看看，点赞、留言、送礼、写信。
- 偷菜偷蛋：每块地 / 每只动物每人只能偷一次，最多偷走一小份，主人至少留一半；每天最多偷 8 次。被看家狗抓到要赔主人一小笔钱（🪙10–60），当天不能再偷这家；朋友在你家被狗抓到，罚款给你。朋友也会来偷你，动态里能看到，可以去「回访」。
- 家产排行：比金币木材、房子（含加盖的楼层）、土地、家具、车、牲畜、仓库，不比步数。运动和屏幕数据永远不公开。
- **隐私和心情**（D30）：朋友能不能看到「我完成了今天的目标」「我正在运动」「我的精力表情」，三个开关全部默认关闭。**安静模式**：不显示排行，不看朋友的运动和精力表情，只管自己的小家。健康页只有自己看得到。
- 全镇总家产决定小镇等级，镇中心广场跟着升级（喷泉、长椅、钟楼……），是全街一起的目标。

## 七、设计原则

- 每天农活（种菜、偷菜）有上限，用完提示「今天的活干完了，去过你的生活吧」。收获、卖、买、布置不占次数。
- 只为真实的社交事件推送（礼物、点赞、留言、来信、被偷），不催你收菜。
- 健康数据默认只有自己看得到；原始健康数据只留在手机上，服务器只存游戏结果。
- 外观完全由玩家决定，不受数据影响；精力只影响表情和动作。
- 包容：轮椅推动算步数，小人可以坐轮椅；有休息日 / 生病选项。
- 精力倍率（睡不好运动奖励打折）是对最初「奖励永不惩罚」原则的修改，用休息日兜底。
