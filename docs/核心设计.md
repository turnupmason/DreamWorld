# 核心设计：为什么玩、玩到最后玩什么

> 回答 Mason 2026-11-06 的问题（需求 #12）：这个游戏最终目的是什么？为什么人要花时间？卖点是什么？什么都有了、钱花不完，游戏是不是就死了？不运动的人，是不是就只是个农场游戏？运动多的朋友家又漂亮又有动态，自己会不会有压力？
>
> 状态标记：✅ v0.4.0 已经做进游戏 · 📝 提议，还没做 · ⏳ 等 Mason 决定

## 一句话定位

**一个靠你真实生活运转的小镇：你过得好，迷你的你就过得好。**

它不是套了游戏外壳的健身 App（那种 App 只奖励能跑的人），也不是加了计步器的农场游戏（那种游戏靠肝和氪金）。它是一面镜子：小镇里的一切都来自你现实里的一天。

## 零（新）、卖点和亮点（需求 #35，2026-11-09，D363，取代下面 D304 的一句话）

> Mason：「我觉得要突出我们社交，仅限跟朋友的小镇……我已经不知道我们的亮点，卖点是什么了。」

- **一句话**：只住你和好朋友的小镇。你们现实里好好过一天，小镇里的家就一起变好。（英文：A tiny town for you and your closest friends. Live well, and your homes grow together.）
- **卖点（只有一个）**：一个只属于你和好朋友的小镇，靠你们真实的生活长大。
- **亮点（3 个，对应 3 个标签）**：朋友就住隔壁（👫）；你的一天变成你的家（🏡 / 🙂）；和朋友比一局（投篮、点球、迷你高尔夫）。
- 详细的理由、第三方测评和取舍见 `精简方案.md` 第十二、十三节。下面 D304 的「镜子」仍然是发动机，只是对外先讲朋友。

## 零、卖点只有一个（回答需求 #30，2026-11-09，D304）

> Mason：「我们目前这个游戏的亮点跟卖点是什么？我们做这么多细节，到底在做什么？全是亮点就等于没有亮点了。」

### 一句话

**你在现实里好好过一天，你和家人朋友的小镇就好一点。**

英文（App Store 副标题）：**Live well. Build your dream town.**

### 唯一的卖点：镜子

现实里的好习惯（走路、运动、睡好、少刷手机）是你在游戏里过上好日子的主要来源，而且这份「好」看得见：家、院子、车、去过的地方、只能靠现实拿到的纪念品。

别的产品都只做到一半：

| 产品 | 有什么 | 缺什么 |
| --- | --- | --- |
| 动物森友会、星露谷 | 好看的生活和家 | 和你的现实无关，家漂亮只代表玩得久 |
| Pikmin Bloom、Pokémon Sleep | 连上了一项健康数据 | 没有「过日子」，没有家，没有身边的人 |
| Finch（自我照顾小鸟） | 好习惯换养成 | 一个人玩，没有小镇和家人 |
| 健身 App | 圆环和数字 | 只奖励本来就爱运动的人，没有想要的东西 |

**镜子 = 现实里的好习惯 → 看得见的梦想生活**，这是只有我们有的。

### 两根柱子（撑起镜子，但不是卖点本身）

1. **和真实的家人朋友住一个镇**：镜子有了观众和温度。互相看得见、一起做事，但不比较、不催（安静模式、比家不比人）。
2. **一个让人想要的世界**：家、车、小镇、旅行要做得细、做得好看，镜子里的奖励才值得追。

### 其他全是布景

体育联赛和竞猜、小游戏、几十种店、音乐、交通、天气……它们让世界看起来是活的，但**不对外宣传，也不能长成要人天天去玩的系统**。

### 以后每个功能先问三个问题

1. 它有没有把现实里的好习惯变成看得见的东西？
2. 它有没有让你和家人朋友更近？
3. 它有没有让人愿意每天来看一眼（但不催）？

一个都答不上 → 不做，或者只做成背景（不加入口、不推送、不做成任务）。

### 用这三个问题看现在的东西

| 东西 | 结论 |
| --- | --- |
| 健康奖励、纪念品、奖杯、家和院子、车、朋友住一条街、休息日和安静模式 | **核心**，继续做深 |
| 小游戏、体育联赛、各种店、音乐音效 | **布景**：保留，不再扩成大系统 |
| 竞猜 | **小心**：和「好好生活」的形象相反，还要提高年龄分级。v0.57 起只能在体育场里押（手机上看不到赔率）；建议以后默认关掉，在设置里自己打开 |
| 游戏里打工、卖东西挣钱 | **小心**：如果游戏里挣得比现实多，镜子就碎了。打工收入要一直明显少于现实奖励（`数值平衡.md`） |

### 新的大世界怎么才有意义（需求 #30 的大地图）

大世界不是新的卖点，是把镜子放大：

- **现实走得多，游戏里去得远**：去别的城市、坐飞机出国的钱来自现实；好好生活一段时间（比如连续一周达标）送一张车票或机票。
- **旅行的收藏 = 生活日记**：每去一个地方拿到当地的东西（邮票、明信片、特产、照片），摆在家里。朋友来你家，看得到你这一年去过哪里。
- **小镇只住你认识的人**：这正是第二根柱子。
- **通勤让交通有用，但不能变成苦差**：一键出门，路上想看就看、想跳就跳。

### 对外只讲三件事（App Store 截图）

1. 昨晚睡得好 → 小人一早精神，拿到金币。
2. 用这些金币一点点盖起来的家。
3. 家人朋友就住在同一条街上。

> **v0.70.1 补充（需求 #34）**：游戏做得太复杂了，「布景」长成了很多要人管的系统。怎么做减法、新用户前 90 秒怎么走，见 `精简方案.md`（等 Mason 定）。

## 一、为什么人愿意每天花时间：5 个卖点

| 卖点 | 是什么 | 别的游戏为什么没有 | 状态 |
| --- | --- | --- | --- |
| 1. 迷你的你是一面镜子 | 昨晚睡得好，小人今天就精神；你在跑步，小人就在街上跑 | 农场游戏的角色和你无关；健身 App 只有数字和圆环 | ✅（实时同步要等手表 App） |
| 2. 现实是唯一的钱 | 钱最初只能靠睡觉、走路、运动、少刷手机得到（v0.14 起也能打工、卖东西；v0.44 起不用木头，D243），花钱买不到 | 大多数游戏可以充值买家产，家漂亮不代表什么 | ✅ |
| 3. 家是你生活的日记 | 「纪念品」只能在现实里做到才拿到（连续 3 晚睡好 → 月亮夜灯）。一年后，你的家里摆满了这一年的真实成就 | 别的游戏的东西都能买到或刷到 | ✅ 7 件，📝 以后上百件 |
| 4. 一条街的朋友 | 住在一条街上的是你真实的朋友。不用聊天，看一眼街上就知道谁在跑步、谁家的菜熟了；可以写信、送礼、偷一点菜 | 社交游戏里多是陌生人；聊天软件又太「重」 | ✅（现在是模拟朋友，要等服务器） |
| 5. 一个希望你放下手机的游戏 | 少刷短视频本身就是收入（v0.44 起农活不限次数，D243） | 别的游戏都想让你多玩一会儿 | ✅ |

**每天花多少时间**：目标是每天 2–3 次、每次 2–5 分钟。早上看看昨晚睡得怎样、领奖励；白天走路运动；晚上收菜、看看朋友、写封信。

## 二、什么都有了、钱花不完，游戏会不会死？

分三层解决。

### 1. 钱不会无限多（✅ v0.4.0）

- 每天从现实里拿到的钱有上限：步数最多算到自己目标的 150%，运动每天最多算 90 分钟，农活每天 24 次。
- 越往后东西越贵：房子从 🪙0 到 🪙25,000；加盖楼层每多一层贵 1.5 倍（城堡盖到 6 层要 🪙13,350 🪵267）。
- 所以钱是「慢慢攒」的，不会突然花不完。

### 2. 有钱买不到的东西（长期目标）

| 目标 | 说明 | 状态 |
| --- | --- | --- |
| 多层楼 | 房子可以一层层往上盖，每层是独立房间，自己设计 | ✅ v0.4.0 |
| 纪念品 | 只能在现实里拿到，不能买。以后可以有很多：第一次走 1 万步、第一次 5 公里、连续 30 天早睡、一整年没断…… | ✅ 7 件，📝 扩充 |
| 季节限定 | 跟着真实日历的春夏秋冬和节日：只在那个季节能种的花、能做的装饰，过了就没了 | 📝 |
| 小镇共建 | 全街一起攒材料修桥、盖图书馆、办丰收节，完成后广场上真的多出来 | 📝（现在有全镇总家产 → 广场升级） |
| 图鉴收集 | 作物、鱼、动物品种、纪念品的收集册 | 📝 |
| 年度回顾 | 年底用你这一年的真实数据生成一本小镇相册：「这一年你睡了多少个好觉，你家多盖了两层」 | 📝 |

### 3. 游戏本来就不用「通关」

这个游戏的目的是帮你把每一天过好。就算家已经很满了，它也会变成一本活的日记：每天早上小人告诉你昨晚睡得怎么样，朋友还住在街上，季节还在变。我们追求的是「每天来看一眼」，不是「每天肝几个小时」。

## 三、不运动的人，是不是就成了农场游戏？

### 1. 收入不只来自运动（✅ v0.4.0）

- 每个人都会睡觉、走路、用手机：睡眠、步数、少刷短视频、正念都能赚钱。
- **目标跟着自己走**：步数目标 = 你最近 7 天的平均 × 1.1（3,000 到 12,000 步之间）。平时走 3,000 步的人和走 12,000 步的人，走到自己的目标拿到的一样多。比的是「比昨天的自己多一点」。
- 生病、带娃、倒班：选「休息日」，奖励照发、不打折。

### 2. 农场里本来就有现实

| 设计 | 状态 |
| --- | --- |
| 小人的表情和动作跟着你的精力走（累了会打哈欠、坐下） | ✅ |
| 纪念品：你的生活摆在家里 | ✅ |
| 「夜里长」：昨晚睡眠 80 分以上，夜里种下的菜第二天多收一份 | 📝 提议 |
| 真实天气：你那里下雨，菜地自动浇水、小人打伞 | 📝 |
| 真实季节：冬天种冬菜，春天开樱花 | 📝 |

### 3. 就算真的只当农场游戏玩，我们也有自己的东西

- 街上住的是你真实的朋友，不是陌生人；
- 写信、送礼这种「慢社交」，不用秒回；
- 家里的纪念品是你生活的证明；
- 每天几分钟就够，不用肝，不能氪。

## 四、运动多的朋友让人有压力，怎么办？（✅ v0.4.0）

原则：**比家，不比人；比自己，不比别人。**

1. **默认什么都不公开**：步数、睡眠分、心率永远不给任何人看。「完成了今天的目标」「正在运动」「精力表情」三个开关，全部默认关闭，在「健康 → 隐私和心情」里自己选。
2. **安静模式**：一键打开后，不显示排行，不看朋友的运动和精力表情，只管自己的小家（健康页和动态页都能开）。
3. **收入公平**：按自己的目标算、最多 150%，运动每天最多 90 分钟。别人家漂亮，主要是因为坚持的天数多，而不是跑得更多。
4. **没有运动排行榜**：排行只比家产；动态里没有运动数字。朋友来信模板也改了，不再写「今天走了一万多步」。
5. **健康页只有自己看得到**，页面顶上写明了。
6. 📝 以后：用鼓励代替比较，比如朋友睡得不好时，可以给他送一碗汤。

## 五、新用户的第一分钟（✅ v0.4.0）

Mason：「打开软件的界面全是文字，新用户需要介绍，不然一头雾水。」

- **开屏**：背后就是真实的小镇在慢慢转，前面只有标题、一句话、一个「开始」按钮。
- **3 张图片故事**，每张一句话：睡得好小人就精神 → 动一动就有金币和木材 → 种地盖房和朋友做邻居。可以跳过。
- **捏小人**：镜头对准你的小人，换衣服、发型马上在小镇里看到。
- **选分心 App** 和每天的上限，两行字说明健康数据和隐私。
- **进游戏后手指引导 6 步**：点地面走过去 → 点熟了的小麦收割 → 领取现实奖励 → 在空地种菜 → 去看小镇 → 看健康页。每步只有一句话，做了才进下一步，随时可以跳过。老玩家不会看到。

## 六、多层楼（✅ v0.4.0）

Mason：「楼可以设计成最后建 2 楼、3 楼、4 楼等等，每个层非常多的自己设计的地方。」

| 房子 | 自带层数 | 最多层数 |
| --- | --- | --- |
| 帐篷 | 1 | 1 |
| 小木屋 | 1 | 2 |
| 小平房 | 1 | 3 |

| 中式庭院 | 1 | 3（加盖成楼阁） |

- 价格见 `数值表.md`「加盖楼层」，越高越贵。
- 每层是独立房间：自己的墙纸（12 种）、地板（8 种）、家具。在哪层买家具就摆在哪层。
- 楼梯在右后角。点楼梯或顶上的「1F / 2F / 3F」，小人先走到楼梯再上下楼；顶层是楼梯口和栏杆。
- 外面看，房子随层数长高：现代别墅一层层往上叠，中式庭院变成多层楼阁。
- 搬去层数少的房子时，放不下的家具收进仓库；搬回来时楼层还在。
- 📝 以后：屋顶花园 / 露台、地下室、每层起名字（卧室层、健身层……）。
