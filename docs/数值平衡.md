# 数值平衡（物价、收入和支出）

> v0.23.0 定的（Mason 需求 #23：「你要算一个物价平衡。收入，支出，东西价格要合理。而且不能太便宜，不然得的太简单了」）。
> 价格都在 `prototype/js/data.js` 里：先写原价，文件最后的 `rebalance()` 按 `PRICE_X` 统一乘上去（结果在 `docs/数值表.md`）。改价格就改 `PRICE_X` 或者原价，再跑 `node docs/生成数值表.js`。

| 三环（活动 25、锻炼 25、站立 15，全合 +40） | 0 | 🪙65 | 🪙105 |

| 正念（每分钟 🪙5，最多 10 分钟） | 0 | 🪙10 | 🪙50 |

## 二、价格怎么定

目标是「大件要攒几周到几个月，小东西几天」，不会一下就全买齐：

| 东西 | 普通玩家要攒多久（目标） |
| --- | --- |
| 第一次升级房子（小木屋） | 2–3 天 |
| 家庭房（两层小楼、农舍、牧场平房） | 3–4 周 |
| 现代别墅、花园别墅 | 6–7 周 |
| 中式庭院、玻璃屋、维多利亚 | 2.5–4 个月 |
| 豪宅 / 山间大木屋 | 4–5 个月 |
| 城堡 | 8–9 个月 |
| 第一辆车（小轿车） | 1 周 |
| 豪车 / 跑车 | 1.5–2 个月 |
| 超级跑车 / 房车 | 3–4 个月 |
| 一件大家具（床、沙发） | 1 天左右 |
| 一件衣服 | 半天到 1 天 |
| 吃一顿饭 / 看一场电影 | 一天收入的 3%–10% |

所以在原价上统一乘了（`PRICE_X`）：房子金币 ×5、木材 ×2.5；车 ×3；家具、院子里的东西 ×2.5；奖杯专属 ×3；扩建菜地 / 牧场 / 果园 / 池塘金币 ×2、木材 ×1.5；买地、搬家 ×2.5；车库 ×1.5；衣服 ×2.5；宠物 ×2、宠物粮 ×1.5；加盖楼层每格 🪙100 + 🪵1.6。商场：电影 🪙45、抓娃娃 🪙20、美食 🪙15–55；送货最低 🪙30；夜校 🪙200 一节；保释 🪙400，警察罚款 🪙150–800。小镇等级门槛 ×4（因为房子更值钱了）。

**不改的**：种子、树苗、小牲畜的价格和卖价（种地养殖自己是平衡的：投入、等待、卖出），打工的时薪。

## 四、钱花在哪（支出）

- **一次性的大件**：房子、加盖楼层、扩建农场、车、车库、家具、院子里的东西、衣服、宠物。
- **经常花的**：种子、小牲畜、宠物粮、吃饭（吃饱 3 小时打工多挣 20%）、看电影（送海报）、抓娃娃（送玩偶，集齐送巨型泰迪熊）、夜校（证书涨工资）、送货费。
- **犯错的代价**：偷东西被抓的罚款、保释金。

## 五、以后要再看的

- 种地的收入是按演示用的「分钟」算的。上线前作物和牲畜改成真实的小时（D26）以后，种地一天能挣的会变少，要重新算一遍这张表，可能再调低一点房车价格，或者提高作物卖价。
- 有服务器以后，可以看真实玩家一天平均挣多少，再微调 `PRICE_X`。

## 银行、贷款、股票（v0.26）

- **存款利息**：每天 0.2%，最多算 🪙50,000（每天最多 🪙100，比一天普通收入 🪙500 少得多）。存钱是为了攒大件，不是主要收入。
- **贷款**：首付 20%，手续费车 8%、房 12%。例：SUV 🪙12,000 → 首付 🪙2,400，每天还 🪙741，14 天，一共多付 🪙768。房子按 30 天分，每天还款大约是普通玩家一天收入的一半到两倍，所以贷款买房要先想想自己每天挣多少。
- **股票**：日波动约 ±5%，长期每天平均涨约 0.05%；买卖各 1% 手续费。低买高卖一来一回先亏 2%，所以靠炒股挣不了大钱，主要是好玩。
