# 精简方案：做减法（需求 #34）

> Mason 2026-11-09：「你要仔细思考我们这个产品的受众人群是什么。我们这个软件做的太复杂了。软件必须在 30 秒内让用户完全明白它的核心价值并完成首次互动……前 90 秒决定次日留存……没人会在游戏里看里面体育游戏，没人会贷款……从简才好，给我仔细分析游戏里的取舍。如果都是亮点的话那就没有亮点了。」
>
> 状态：**提议，等 Mason 定**（第十节的问题）。定了以后从 v0.71 开始做。

## 一、结论（先看这个）

1. **Mason 说得对，而且比想象的更严重。** 我用全新存档、手机尺寸实测了一遍：新用户要先过 **7 个画面**（开屏、强制登录、3 张故事图、捏小人、选 App + 时长 + 健康权限）才能进游戏；进去后第一屏有 **21 个按钮**、3 条会往下掉的需求条、一个「第 4 名」排行；引导第 2 步点麦子会**错开商店**（bug）；第一份奖励是和现实无关的「入住礼包」，里面还有早就取消了的木头。**前 90 秒里，用户一次也没看到「现实里的我 → 游戏里变好」**。
2. **我们的 Aha 时刻只有一个：「我昨天真实走的路、昨晚真实睡的觉，变成了我家里的一样东西。」** 好消息是 iPhone 本来就自动记步数，健康数据里有历史：**第一次打开就能用「昨天」的真实数据发奖励**，不用等到明天。这是我们最大的武器，现在完全没用上。
3. **取舍：核心只留 4 样**：健康奖励（镜子）、家（花钱的地方）、小菜园（每天 10 秒的手感）、朋友一条街（温度）。其余的大部分**藏起来**（代码不删，用开关关掉），少数违反我们自己原则的**砍掉**（竞猜、贷款股票、需求条、生病警察罚款、农场会坏）。
4. **底部从 6 个标签变成 3 个**：家、街坊、我。首页最多 8 个能点的东西。
5. **新的前 90 秒**：不登录 → 一键选小人 → 读健康 → 看到「昨天走了 6,214 步、睡了 7 小时」变成金币 → 给家买第一样东西、看它放进屋里 → 收一棵菜 → （可选）邀请朋友住隔壁。登录和选分心 App 挪到以后。

## 二、我们的用户是谁

产品概念里写的核心用户：**美国 20–35 岁、每天刷短视频超过 1 小时、刷完觉得空、试过戒但没坚持住的人**。

他们打开我们的那一刻是什么状态：

| 他们是 | 所以 |
| --- | --- |
| 不是来玩「大游戏」的，是在想刷 TikTok 的那几秒打开我们 | 每次打开要在几秒内拿到一点好心情，不能有要学的东西 |
| 注意力被短视频训练过，没耐心看说明 | 不能有文字介绍、不能有 7 个设置画面 |
| 带着一点愧疚（又刷了一小时） | 我们要让他们觉得「我今天其实还不错」，不能再给压力（需求条、排名、东西坏掉） |
| 每天来 2–3 次、每次 2–5 分钟（`核心设计.md`） | 每次只做 1–2 件事：领奖励、添一样东西、看一眼朋友 |
| 次要用户：动森 / 星露谷玩家、有 Apple Watch 的人、朋友小圈子 | 动森玩家会喜欢「家」；他们也不需要飞机、股票和球票 |

**他们不需要的**：一个模拟真实城市的世界（公交线路、红绿灯、州县物价、通勤、贷款）。那是「模拟人生 + 城市天际线」的用户，不是我们的用户。我们越像一个大游戏，越像他们想戒掉的那种东西。

## 三、实测：现在新用户的前 90 秒

2026-11-09，全新存档（`http://[::1]:5173`，和 Mason 的存档、测试存档都分开），375×812 手机尺寸。秒数是按真人速度估的。

| 大约时间 | 画面 | 用户要做什么 | 问题 |
| --- | --- | --- | --- |
| 0–3 秒 | 开屏：标题 + 「开始」 | 点开始 | 没问题 |
| 3–15 秒 | **登录**：Apple / Google / 邮箱 | 登录（真机上还要 Face ID） | 还没看到任何好处就要注册，最容易流失的一步 |
| 15–25 秒 | 3 张故事图 | 读字、点 3 次「下一步」 | 用文字解释，而不是让人亲手体验 |
| 25–40 秒 | 捏小人：衣服、发型、颜色、步行 / 轮椅 | 选一堆 | 可以以后再改，第一次只要一键 |
| 40–60 秒 | 选分心 App（6 个）+ 每天上限（4 个选项）+ 健康说明 | 3 个决定；真机上还会弹「屏幕使用时间」「健康」两个系统权限框 | 一页里最重的决定；屏幕时间权限在第一天根本用不上 |
| 60–70 秒 | 进游戏：**天黑**（按真实时间，晚上 7 点后）、21 个按钮、3 条需求条、「第 4 名 · 家产 5,372」、待领取、一键收获 | 看懂这一屏 | 太多；排名第一眼就在比较；晚上第一次打开看不清 |
| 70–80 秒 | 引导 1：点地面走过去 | 点 | 没问题 |
| 80 秒～ | 引导 2：「小麦熟了！点它」 | 点手指指着的麦子 | **bug：「🔓 多一块地 🪙200」的牌子盖在麦子上，点了打开商店的「土地」页**，回不到引导 |
| 之后 | 引导 3：领奖励 | 点「待领取」 | 第一份奖励是「入住礼包 +🪙500 +🪵10 +种子」：**和现实无关**；木头 v0.44 就取消了 |

截图：开屏后第一屏、引导第 2 步错开商店、第一份奖励（在对话里发给了 Mason）。

**结论**：用户在 60 秒左右才第一次碰到游戏，90 秒时还卡在引导第 2 步，**整个第一次打开都没体验到「现实 → 游戏」**。

## 四、我们的 Aha 时刻

别的产品的 Aha：Spotify 听到第一首喜欢的歌；Forest 种下第一棵树；Pikmin Bloom 走几步就开出第一朵花；Finch 给小鸟起名字后它马上对你说话。

**我们的 Aha：「这是我昨天真实的一天，它让我的小家变好了。」**

拆开就是 3 个瞬间，都要在 60 秒内发生：

1. **被看见**：「昨天你走了 6,214 步，昨晚睡了 7 小时 12 分。」小人伸个懒腰、开心地蹦一下。
2. **变成钱**：金币一个个飞进钱包（数字要小、要好懂，比如 +🪙120，不是 2,000 起步）。
3. **变成家**：马上用这笔钱买第一样东西（3 选 1：一盏灯、一盆花、一只小猫窝），看它「咚」地放进屋里。

做法上的关键：

- **iPhone 不戴手表也自动记步数**，几乎每个人的健康数据里都有昨天的步数；有手表或睡眠记录的人还有昨晚的睡眠。所以第一次打开就能发「真实的」奖励。
- 健康权限要在**这一刻**请求：「看看你昨天过得怎么样？」→ 系统权限框 → 马上看到结果。有理由、马上有回报，用户才愿意点「允许」。
- 不给权限的人：给一份起步金，并给一个「现在出门走 2 分钟试试」的小目标，走完回来就看到金币。
- Swift 现在只读「今天」的步数和「昨晚」的睡眠（`HealthBridge.swift`），要加读「昨天的步数」（等 Mason 在 Mac 上编译）。

## 五、新的前 90 秒（剧本）

| 时间 | 画面 | 用户做 | 目的 |
| --- | --- | --- | --- |
| 0 秒 | 小镇在后面慢慢转（白天的样子），一句话「Live well. Your little home grows.」+「开始」 | 点 | 不登录 |
| 5 秒 | 3 个现成的小人（男 / 女 / 轮椅也在里面），点一个就是你；「以后随时换」 | 点 1 次 | 有归属感，不花时间 |
| 12 秒 | 小人站在空空的小屋里打哈欠：「看看你昨天过得怎么样？」→ 健康权限 | 点允许 | 权限有理由 |
| 20 秒 | **揭晓**：「昨天 6,214 步 🚶 · 昨晚 7 小时 😴」，小人醒来伸懒腰，金币飞进钱包 | 看 | **Aha 第 1、2 步** |
| 35 秒 | 「给家添第一样东西」：3 张大图 3 选 1 | 点 1 次 | **Aha 第 3 步** |
| 45 秒 | 东西放进屋里（可以拖一下换位置），小人走过去用它（坐上去、摸猫） | 看 / 拖 | 「这是我的家」 |
| 60 秒 | 院子里一棵菜在发光：「熟了，点一下」 | 点 | 手感，知道以后每天来干什么 |
| 75 秒 | 「叫个朋友住隔壁？」分享链接（可以跳过） | 点或跳过 | 社交，带新用户 |
| 90 秒 | 「明早再来：你今晚的觉会变成金币。」 | — | 给第二天一个理由 |

挪到以后的：

- **登录**：第一次邀请朋友、或者第 3 天提示「登录后换手机也不会丢家」时再登录。
- **选分心 App**：第 2 天以后，在「我」里出现一张卡片「想少刷哪个 App？少刷也能挣钱」。
- **捏小人细节、隐私开关、安静模式、休息日**：都在「我」里，需要时再找。

## 六、全部系统的取舍

判断标准（三个问题，`核心设计.md` 第零节写过，这次严格执行）：
1. 它是不是「现实好习惯 → 看得见的家」这条线的一部分？
2. 新用户第一周需不需要它？
3. 它会不会给人压力（催、罚、比）？

### 留下，做精（核心）

| 系统 | 怎么改 |
| --- | --- |
| 健康 → 金币 + 小人表情（睡眠、步数、运动；少刷手机第 2 天起） | 每天早上一次「揭晓」动画，是每天打开的理由 |
| 家：房子、家具、院子摆设、设计模式 | 首页就是家，大而清楚；商店改成家里直接打开的目录，买了直接到家（不用走去店里） |
| 小菜园 | 只留菜地、少量作物；点一下收；**不会坏** |
| 纪念品 / 奖杯（现实做到才有） | 摆在家里，是「镜子」最好的证明 |
| 朋友住一条街：串门、送礼、写信、偷一棵菜、动态 | 「街坊」标签只放这些 |
| 小人外观、休息日、安静模式、隐私开关 | 放进「我」 |
| 音乐音效、天气、昼夜 | 布景；夜里要像「暖黄灯光的晚上」，不能黑到看不清 |

### 藏起来（代码留着，开关默认关；以后看数据再一个个放出来）

| 系统 | 以后可能的样子 |
| --- | --- |
| 世界页、大地图、16 个城市、飞机 / 火车 / 轮船、出行 App、护照 | 变成一个奖励：现实连续一周达标 → 一张「明信片旅行」，一键看一段飞过去的动画，带回当地纪念品摆在家里 |
| 小镇里走进 23 家店买东西、店里推购物车结账 | 小镇只当风景和朋友的家；买东西在目录里 |
| 体育联赛、赛程、球票、看台 | 布景（远处体育场有欢呼声） |
| 12 个小游戏（网球、投篮、点球、保龄球、游泳、迷你高尔夫、卡拉OK、抓娃娃、钓鱼、本垒打……） | 以后最多挑 1–2 个，做成和朋友一起玩的 |

### 砍掉（违反我们自己写下的原则）

| 系统 | 违反了什么 |
| --- | --- |
| 体育竞猜 | 和「好好生活」相反，还会抬高 App Store 年龄分级 |
| 贷款、股票、存款利息 | 没人来这里理财；把「家」变成了金融 |
| 饱腹 / 社交 / 娱乐需求条和后果 | 一直往下掉 = 一直在催；`产品概念.md` 原则：不催 |
| 生病、诊所、警察、拘留、被狗罚款 | 惩罚；原则 1「奖励，不惩罚」 |
| 农场会坏、牲畜要喂（D243 / D244） | 原则 1「没做到时不扣资源、不让东西坏掉」。**这是 Mason 自己定的，要 Mason 重新确认** |
| 市场浮动收购价、拉货去卖 | 游戏里挣钱太多，镜子就碎了（`核心设计.md` 第零节） |
| 第一份奖励里的木头 | v0.44 已经没有木头了，是遗留 bug |

## 七、精简后的样子

**底部 3 个标签**：

| 标签 | 里面只有 |
| --- | --- |
| 🏡 家 | 你的家和院子、小菜园、「添东西」按钮（目录）、待领取的奖励 |
| 🏘️ 街坊 | 朋友住的那条街、去朋友家、送礼、写信、动态 |
| 🙂 我 | 今天的健康（只有自己看得到）、纪念品和奖杯、小人外观、设置 |

**首页顶上只有**：小人头像 + 心情、金币。其他都拿掉。

**首页能点的东西 ≤ 8 个**（现在 21 个）。

## 八、怎么做

- **不删代码，先用开关藏**：`data.js` 加一个 `FEATURES` 表（世界、交通、体育、小游戏、店、打工、手机、需求条、贷款……），简单版默认全关；开发控制台 🛠 里能一键切回「完整版」，Mason 想看以前的东西随时能看。以后确定不要的再真正删掉。
- **分 3 版**：
  - **v0.71 精简**：加开关、关掉「藏」和「砍」的系统、底部 3 个标签、首页只留核心、商店变目录、修引导第 2 步的 bug、去掉木头。
  - **v0.72 新的前 90 秒**：按第五节的剧本重做开屏和引导（原型里用模拟的「昨天的数据」；Swift 加读昨天步数，等 Mason 在 Mac 上编译）。登录和选分心 App 挪到后面。
  - **v0.73 每天回来的理由**：每天早上的「揭晓」、小人对你昨天的反应、纪念品获得的瞬间、朋友的动态。
- **衡量**：打开到第一份真实奖励 < 30 秒，到第一样东西放进家 < 60 秒；引导完成率；内测时次日留存 ≥ 40%、7 日留存 ≥ 15%（`产品概念.md` 的关口二）。

## 九、以后怎么防止再变复杂

1. **新功能先过三个问题**（第六节），再加一条：**「新用户第一周需不需要它？」** 不需要就只能进「以后」清单，或者只做成布景（没有按钮、没有说明、没有要管的数字）。
2. **首页按钮上限 8 个、底部标签上限 3 个**：要加一个，就得拿掉一个。
3. **每一版先对着「新的前 90 秒」走一遍**，变慢了就不能发。
4. **我（Claude）要把关**：以前 `核心设计.md` 第零节（v0.57）就写了「布景不能长成要人天天去玩的系统」，但后来 v0.58–v0.70 连续做了 13 版交通、旅行、球票。我应该在做之前就指出来，而不是照着做。以后碰到和原则冲突的需求，我先说明冲突、给出更简单的做法，再由 Mason 决定。
