## Mason 的偏好

- 一律用中文回复。
- 所有信息都要写进 md 文件，新对话直接读文档就能接着做。
- 每次更新都写更新日志、升版本号、打标签、推送到 GitHub。
- 这是 iPhone 手机游戏，不是电脑版。正式版用 Swift。
- 画风：喜欢网页版的 2.5D 等距卡通风格（「之前网页的样子非常好，只需要完善就好」）；不喜欢 Kenney / Quaternius 那种 3D 低多边形（「3d 太丑了」）。
- 想要像《模拟人生》一样细致：房子内饰、车、田地、牲畜都能自己设计。
- 健康数据要用得很细：睡眠、三环、训练、呼吸、心率，以及 Oura、Whoop、Apple Watch 等设备。

## 网页原型留下的教训（正式版要避免）

- 自己的家只是一块悬空的板，周围没有东西 → 正式版的家周围要有邻居、马路、树林、广场。
- 商店分类放在横向滚动条里，「车」「房子」被挤到屏幕外没人发现 → 分类要一眼都能看到。
- 窄屏上右侧按钮被裁掉 → 按手机尺寸设计，要考虑安全区。
- 一键收获是瞬间完成的，小人到处乱跑 → 正式版小人由玩家操控，每个动作都要走过去做。
- 画风本身 Mason 认可，要做的是把细节和内容补足。
