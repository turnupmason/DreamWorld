## #3 · 2026-11-06 · 自己的家、商店、农场、小镇

**原话要点**：

- 以后都用中文。
- 建了 GitHub 仓库专门放这个软件：https://github.com/turnupmason/DreamWorld
- 小人只有头和身体，要有手有脚。
- 要有商店：买种子、牲畜、地、家具、车、房子。所有钱都从运动（fitness）和减少刷短视频的时间兑换。

- 整个小镇（好友互相建设的）有一个总资产排名。
- 植物、牲畜的收获，包括下的崽，都可以卖钱。
- 把 Town 换成自己的家，非常详细：房子内饰、车子、田地、牲畜都可以自己设计，跟《模拟人生》一样；另外有一个 Town 页显示整个小镇的情况。

**状态**：✅ v0.2.0 网页原型。偷菜和排行做了缓和处理（见 `决策记录.md` D4、D5）。
